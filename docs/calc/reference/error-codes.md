# Error codes

Every error carries a stable `code`. Clients should branch on the code, never on the message. When the docs are built, this table is generated by scanning the source of the core library and of the what-if plugin for every error they raise, so a new code shows up here automatically. The **From** column says which package raises it.

```python exec="on"
import ast
import pathlib

import pylibs_calc
import pylibs_calc.errors as errors
import pylibs_calc_whatif
import pylibs_calc_whatif.errors as whatif_errors

HINTS = {

classes = {
    n: c
    for module in (errors, whatif_errors)
    for n, c in vars(module).items()
    if isinstance(c, type) and issubclass(c, errors.CalcError)
}
found = {}
where = {}
for package, label in ((pylibs_calc, "core"), (pylibs_calc_whatif, "what-if")):
    root = pathlib.Path(package.__file__).parent
    for path in sorted(root.rglob("*.py")):
        for node in ast.walk(ast.parse(path.read_text())):
            if isinstance(node, ast.Call):
                name = getattr(node.func, "id", None) or getattr(node.func, "attr", None)
                if name in classes:
                    code = next(
                        (k.value.value for k in node.keywords if k.arg == "code" and isinstance(k.value, ast.Constant)),
                        classes[name].code,
                    )
                    found.setdefault((classes[name].status, code), set()).add(name)
                    where.setdefault((classes[name].status, code), set()).add(label)
found.setdefault((errors.Forbidden.status, errors.Forbidden.code), {"Forbidden"})

    print(f"| {status} | `{code}` | {', '.join(f'`{n}`' for n in sorted(names))} | {source} | {HINTS.get(code, '—')} |")
```

## Exception classes

In Python, catch the class and read `.code`, `.path`, `.status` and `.message`:

| Class | Status | Raised when |
| --- | --- | --- |
| `CalcError` | — | Base class of every error below |
| `SpecError` | 422 | The request is not a valid calculation |
| `ComputeError` | 422 | Polars failed on valid input |
| `NotFound`, `DatasetNotFound`, `ScenarioNotFound` (from `pylibs_calc_whatif`) | 404 | Something doesn't exist |
| `Forbidden` | 403 | Your `authorize` hook refused |
| `VersionConflict` | 409 | A stale `expected_version` |
| `LimitExceeded` | 413 | Over a `Limits` cap |
| `EngineBusy` | 503 | No execution slot in time |
| `CalcTimeout` | 504 | Past the timeout |

`PluginError` (a `ValueError`, not a `CalcError`) is raised when the engine is built with conflicting plugins, e.g. two plugins registering the same function name.

The HTTP body is:

```json
{"detail": {"code": "unknown_column", "message": "unknown column: notionl", "path": "/query/measures/0/of"}}
```

- `path` is a JSON pointer into the request.
- Validation errors also carry `detail.errors`, with up to 20 problems at once.
